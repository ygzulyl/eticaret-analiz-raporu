# E-Ticaret Müşteri Davranışları ve Harcama Analizi

Bu proje, bir e-ticaret platformundaki müşteri segmentlerini, harcama alışkanlıklarını ve demografik kırılımları inceleyen kapsamlı bir veri analizi raporudur. Pandas, Seaborn ve Plotly kütüphaneleri kullanılarak hazırlanmıştır.

🚀 **[Canlı Raporu Görüntüle](https://ygzulyl.github.io/eticaret-analiz-raporu/)**

## 📊 Analiz İçeriği
* Veri seti keşfi ve eksik veri analizi
* Merkezi eğilim ve yayılım ölçüleri (Tanımsal İstatistikler)
* Demografik ve davranışsal 5 farklı veri görselleştirme çalışması
* Veriden elde edilen stratejik iş içgörüleri

## 🛠️ Yerel Çalıştırma Talimatları
Projenizi yerelde çalıştırmak ve incelemek için:

```bash
# 1. Depoyu klonlayın
git clone [https://github.com/ygzulyl/eticaret-analiz-raporu.git](https://github.com/ygzulyl/eticaret-analiz-raporu.git)
cd eticaret-analiz-raporu

# 2. Sanal ortam oluşturun ve aktif edin
python -m venv venv
source venv/bin/activate  # Windows için: venv\Scripts\activate

# 3. Bağımlılıkları yükleyin
pip install -r requirements.txt

# 4. Jupyter Notebook'u başlatın
jupyter notebook notebook/rapor.ipynb
